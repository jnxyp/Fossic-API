## 复现

本仓库根目录执行（Linux amd64 / Python3.11 为此次锁定及测试目标；其它平台应另行验证）：

```sh
uv pip compile --python 3.11 --python-platform x86_64-unknown-linux-gnu --generate-hashes --output-file requirements.lock requirements.txt
uv pip compile --python 3.11 --python-platform x86_64-unknown-linux-gnu --generate-hashes --constraint requirements.lock --output-file requirements-dev.lock requirements-dev.txt
docker build --target test -t fossic-api-security-test .
docker run --rm --network none --read-only --tmpfs /tmp:rw,size=32m --cap-drop ALL --security-opt no-new-privileges fossic-api-security-test
docker build -t fossic-api-security .
```

测试强制禁用 dotenv 并使用回环端口1的假数据库配置；不要提供生产 env_file。
